# 고정 HTTPS 주소

인터넷 연결을 켤 때마다 바뀌는 Cloudflare 주소 대신, 컴퓨터와 휴대폰 모두 같은 고정 웹 주소로 접속하게 하는 선택 기능입니다. 고정 사이트는 등록된 기기의 공개키와 현재 터널 주소만 보관합니다. 접속하면 사이트가 해당 주소에 새 난수를 보내 기기 서명을 확인한 뒤 브라우저를 현재 주소로 이동시킵니다. 화면, 클릭, 4자리 코드, 세션 쿠키는 사이트를 거치지 않습니다. Mac과 Windows 모두 같은 방식으로 동작합니다.

## 구성

- `site/`: 고정 사이트의 소스(Worker)입니다. `BUCKET`이라는 비공개 R2 저장소 바인딩이 필요합니다.
- 앱 쪽 코드는 저장소 루트의 `fixed_entry.py`와 `server.py`에 들어 있습니다.

## 사이트 배포

1. `site/worker/index.js`를 Worker로 배포하고 `BUCKET`에 비공개 R2 버킷을 연결해 주세요. `site/.openai/hosting.json`은 ChatGPT Sites용 설정입니다.
2. 사이트는 호스팅 쪽이 확인해 주는 로그인 사용자 ID 헤더(`oai-authenticated-user-id`)를 믿고 소유자별로 기기를 한 대 등록합니다. 다른 호스팅에 올릴 때는 **사용자가 임의로 넣을 수 있는 헤더를 믿지 말고**, 호스팅이 검증한 로그인 정보만 이 헤더로 전달하도록 구성해 주세요.
3. `node site/verify-entry.mjs`(Node 22 이상)로 등록, 소유자 격리, 서명 검증, 주소 갱신을 확인할 수 있습니다.

이미 배포된 사이트가 있다면 그대로 쓸 수 있습니다. 앱은 같은 서명 방식을 사용합니다. 개인 사이트 주소는 공개 저장소에 올리지 마세요.

## 앱 설정

- **Windows**: `start-windows.bat --fixed-entry https://고정-사이트-주소`를 한 번 실행해 주세요. 주소가 저장되고 인터넷 연결로 시작합니다. 이후에는 `start-windows.bat --internet`만 실행해도 저장된 주소를 씁니다. 설정을 지우려면 `--fixed-entry clear`를 사용해 주세요.
- **Mac**: 터미널에서 `python3 fixed_entry.py configure https://고정-사이트-주소`를 한 번 실행해 주세요. 이후 Mac 리모컨에서 **인터넷 연결**을 켜면 저장된 주소를 씁니다. 설정을 지우려면 `python3 fixed_entry.py clear`를 사용해 주세요.
- 위 명령은 **16자리 기기 지문**을 보여 줍니다. 개인키는 사용자 전용 폴더(Mac: Application Support, Windows: AppData)에 보관되며 재설치해도 같은 키를 씁니다. 개인키를 복사하거나 공유하지 마세요.

## 처음 연결

1. 컴퓨터의 기본 브라우저에서 고정 사이트에 소유자 계정으로 먼저 로그인해 주세요.
2. 인터넷 연결을 켜면 브라우저에 등록 페이지가 열립니다. 처음 한 번 16자리 기기 지문을 입력해 주세요. 등록 요청은 5분 안에 써야 합니다. 브라우저가 열리지 않으면 Windows 창에 표시된 주소를 직접 여세요.
3. 이후에는 컴퓨터나 휴대폰 어디서든 고정 사이트의 **현재 컴퓨터 열기**를 누르고, Mac이나 PC에 표시된 4자리 코드를 입력한 뒤 승인해 주세요.

인터넷 연결을 껐다 켜면 주소가 바뀌지만, 켤 때마다 같은 키로 자동 갱신됩니다. 소유자 계정별로 한 대를 등록합니다. 컴퓨터를 바꾸면 사이트 소유자가 저장된 등록 레코드를 삭제한 뒤 새 기기를 등록해 주세요.
